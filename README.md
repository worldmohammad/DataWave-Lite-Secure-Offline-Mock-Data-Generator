Since this is a Serverless SPA, setting it up is incredibly simple:

Clone this repository:

git clone https://github.com/yourusername/datawave-lite-mock-data.git


Open the index.html file in your preferred web browser.

Define your columns, click generate, and download your dataset!

🔒 Security & Privacy First

Data privacy laws (like GDPR and CCPA) make using production data for testing incredibly dangerous. DataWave solves this by keeping everything local. We do not track your usage, we do not see your database column names, and we do not store your generated files.
